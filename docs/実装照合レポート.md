# OrderRoom 実装照合レポート

更新日: 2026-08-03

この資料は、現在のフロントエンド・バックエンド実装と、`docs` に書かれている仕様を照合するための作業資料である。仕様の正本は引き続き [ロードマップ](ロードマップ.md)、[MVP仕様](MVP.md)、[DB・API設計書](DB_API設計書.md)、[画面仕様](screens.md) とする。

## 判定区分

### 実装済み

FE/BEどちらか、または両方に利用可能な実装がある。

### 部分実装

一部だけ存在するが、仕様通りの利用者導線としては完了していない。

### 未実装

現在のコードに該当機能がない。

### 仕様差分

実装はあるが、docsの仕様・API契約と違う。

### 方向転換提案

Discussion等で提案されたが、MVP確定仕様ではない。

### 要注意

現在のままだとアプリが動かない、または結合時に壊れる可能性がある。
